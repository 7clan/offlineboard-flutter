# OfflineBoard

An offline-first Flutter task and team-management application focused on local persistence, synchronization, conflict handling, resilient state management, automated testing, accessibility, and mobile performance.

## Planned stack

- Flutter / Dart
- Riverpod
- Dio
- GoRouter
- Drift / SQLite
- REST synchronization layer
